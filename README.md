# 📊 Global Store Sales Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** developed to analyze the sales transactions of a global retail store with branches across multiple countries. The dashboard provides meaningful business insights through data cleaning, interactive visualizations, and sales performance analysis across various geographical locations.

---

## 🎯 Project Objectives

- Perform basic data cleaning and preprocessing.
- Segment sales data by **Country**, **Region**, and **Market**.
- Analyze the **percentage distribution of shipping** based on **Ship Mode**.
- Visualize sales performance across **City**, **State**, **Region**, and **Market**.
- Create supporting tables for each visualization to enable detailed analysis.

---
